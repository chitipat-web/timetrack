🧹 ล้าง Cache

ล้าง Service Worker + Cache เก่าของ RUDY ทั้งหมด เพื่อโหลดเวอร์ชันใหม่
หลังล้างเสร็จ:
1ปิดแอปทั้งหมด (swipe up)
2ลบไอคอนแอปจากหน้าจอ (กดค้าง → Remove)
3เปิด Safari → ไปที่ RUDY URL
4กด Share → Add to Home Screen ใหม่
วิธีล้างใน Safari (หากยังไม่หาย)
iPhone: Settings → Safari → Clear History and Website Data
หรือ: Settings → Safari → Advanced → Website Data → Edit → ลบ pat-web.github.io

Mac: Safari → Settings → Privacy → Manage Website Data → ลบ pat-web.github.io
