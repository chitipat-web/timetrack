RUDY — นโยบายความเป็นส่วนตัว

อัพเดทล่าสุด: 12 มิ.ย. 2026

RUDY เป็นแอปลงเวลาทำงานภายในทีม สร้างโดย Chitipat Keeratimetawin สำหรับใช้ในทีมตนเอง 3 คน

ข้อมูลที่เก็บ

  • อีเมล — ใช้ login ผ่าน Firebase Authentication
  • ชื่อ-นามสกุล — แสดงในแอป
  • บันทึกเวลาเข้า/ออกงาน — บันทึกใน Firebase Realtime Database
  • รูปโปรไฟล์ (ถ้าอัพโหลด) — เก็บใน Firebase
  • โทเค็นแจ้งเตือน push — สำหรับส่งการแจ้งเตือนเข้างาน/ลืม check-out

ข้อมูลที่ไม่เก็บ

  • ตำแหน่ง GPS
  • รายชื่อในเครื่อง
  • รูปภาพอื่นที่ไม่ได้อัพโหลดเอง
  • ไมโครโฟน / กล้อง (ยกเว้นตอนอัพรูปโปรไฟล์)

การใช้บริการบุคคลที่สาม

  • Firebase (Google) — เก็บฐานข้อมูล + Authentication + Push Notification ดูนโยบาย: policies.google.com/privacy
  • Google Gemini API — สำหรับฟีเจอร์ AI ช่วยตอบ ส่งเฉพาะข้อความ ที่ผู้ใช้พิมพ์ตอนใช้ฟีเจอร์ ดูนโยบาย: policies.google.com/privacy

RUDY — Privacy Policy

Last updated: 12 June 2026

RUDY is a time-tracking app for an internal team of 3, built by Chitipat Keeratimetawin for personal team use.

Data we collect

  • Email — for sign-in via Firebase Authentication
  • Display name — shown inside the app
  • Check-in / check-out records — stored in Firebase Realtime Database
  • Profile photo (if uploaded) — stored in Firebase
  • Push notification token — to send work reminders

Data we do NOT collect

  • GPS location
  • Contacts
  • Photos other than the profile photo you upload
  • Microphone / camera (except when uploading a profile photo)

Third-party services

  • Firebase (Google) — database, auth, push. policies.google.com/privacy
  • Google Gemini API — for the AI helper feature; only the text you type into that feature is sent. policies.google.com/privacy

Data deletion

Email chitipat.kao@gmail.com to request deletion of your account and all associated data. We will process it within 7 days.
